## התקנה

1. הורידו את הקובץ לטלפון
2. פתחו אותו — אנדרואיד ישאל אם לאפשר התקנה ממקור לא מוכר, ויש לאשר
3. אם ההתקנה לא מתחילה, ראו "אם משהו משתבש" למטה

**דרישות:** אנדרואיד 7.0 ומעלה. הקבצים רצים על טלפונים 32 ו-64 סיביות
כאחד.

**שדרוג:** מתקינים מעל הגרסה הקיימת, והנתונים נשמרים.

## אם משהו משתבש

**"ארעה בעיה בניתוח החבילה"** — כמעט תמיד אחת משלוש סיבות, לפי השכיחות:

1. **אין מספיק מקום בטלפון.** התקנה צורכת את גודל הקובץ ועוד כמה
   פעמים ממנו לקוד הפרוס. פנו מקום ונסו שוב — זו הסיבה הנפוצה ביותר,
   והיא לא נראית כמו בעיית מקום.
2. **ההורדה נקטעה.** השוו את הגודל בבתים ואת ה-SHA-256 לטבלה שלמעלה.
   אם הם לא תואמים, הקובץ פגום וצריך להוריד שוב.
3. **התקנה ממקור לא מוכר חסומה.** חלק מהיצרנים מציגים את זה כשגיאת
   ניתוח במקום לומר זאת במפורש.

**"האפליקציה לא תואמת למכשיר"** זו הודעה אחרת לגמרי — היא אומרת
שאנדרואיד קרא את הקובץ ודחה אותו, ולרוב פירושה גרסת אנדרואיד ישנה מ-7.0.

### איך משווים SHA-256

ב-Windows, ב-PowerShell:

```powershell
Get-FileHash .\events-reminder-1.3.0.apk -Algorithm SHA256
```

בלינוקס או ב-Mac:

```bash
shasum -a 256 events-reminder-1.3.0.apk
```
